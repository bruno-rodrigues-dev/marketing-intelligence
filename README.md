# Marketing Intelligence — Análise de Clientes e Campanhas

Projeto de análise de dados de marketing utilizando Python, Pandas, SQL, MySQL e Power BI, com foco no comportamento dos clientes, desempenho de campanhas e identificação de oportunidades de segmentação.

## Status do projeto

🚧 Em desenvolvimento

## Objetivo

Analisar dados de clientes, hábitos de compra e campanhas de marketing para identificar padrões de comportamento e gerar insights que apoiem decisões estratégicas.

## Dados

O projeto utilizará o dataset [Customer Personality Analysis](https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis), disponibilizado no Kaggle.

Os dados serão utilizados para investigar o perfil dos clientes, os gastos por categoria de produto, os canais de compra e a resposta às campanhas de marketing.

## Resultados esperados

Desenvolver um dashboard interativo e apresentar insights que ajudem a compreender o comportamento dos clientes, avaliar a resposta às campanhas e identificar oportunidades para estratégias de marketing mais direcionadas.
